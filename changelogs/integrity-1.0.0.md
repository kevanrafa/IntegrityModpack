# Integrity v1.0.0 Changelog

## New Features
- Initial release of Integrity Modpack
- Compatible with Minecraft 1.21.1
- Optimized performance on mid-range systems
- Integration with Fabric mod loader

## Changes
- Configured optimal mod compatibility
- Adjusted client settings for smooth gameplay
- Updated mod configurations for balance

## Fixes
- Resolved shader compatibility issues
- Fixed memory leak in rendering pipeline
- Corrected mod conflicts

## Removed
- Removed experimental mods from previous alpha

## Known Issues
- Occasional frame drops in areas with many entities
- Some keybinds may conflict with custom launchers
